#+DESCRIPTION: Select tree-sitter nodes with avy
#+ID: treesit-mark

Select functions, classes, conditions, loops and blocks in one keystroke: press a key, get [[https://github.com/abo-abo/avy][avy]] labels on the nodes in the window, press a label.

| Label on                                 | Selects                  |
|------------------------------------------+--------------------------|
| start of a function, class, =if=, =for=… | the whole node           |
| ={= of a block                           | the contents, no braces  |

Works in any buffer with a tree-sitter parser, including embedded parsers such as =<script>= in Vue.

* Install

Requires Emacs 29.1+ with tree-sitter and [[https://github.com/abo-abo/avy][avy]].

*** Elpaca
#+BEGIN_SRC emacs-lisp
(use-package treesit-mark
  :ensure (:host github :repo "artawower/treesit-mark.el")
  :bind ("s-q" . treesit-mark-node))
#+END_SRC

*** Straight
#+BEGIN_SRC emacs-lisp
(use-package treesit-mark
  :straight (:host github :repo "artawower/treesit-mark.el")
  :bind ("s-q" . treesit-mark-node))
#+END_SRC

* Customization

| Variable                            | Purpose                                    |
|-------------------------------------+--------------------------------------------|
| =treesit-mark-whole-node-types=     | node types selected whole                  |
| =treesit-mark-block-node-types=     | node types selected without their braces   |
| =treesit-mark-top-level-node-types= | node types selected whole at the top level |
| =treesit-mark-select-function=      | called with =BEG= and =END= of the node    |

Use =treesit-mark-select-function= when a modal editing package needs its own selection state.
